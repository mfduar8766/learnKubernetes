# Getting Started:
1. Docker Desktop is required. In the future will remove minikube since you can run kubernetes in Docker its self.
2. You need minikube for kubernets
3. You need kubectl which comes with minikube
4. Golang version 1.26.2 is beig used here but any version above 1.19.X should be fine.
5. To run this repo you need to:
    ```
    chmod +x ./start.sh
    ```
6. After that execute the script. THis will tell you what you need to install:
    ```
    ./start.sh
    ```
